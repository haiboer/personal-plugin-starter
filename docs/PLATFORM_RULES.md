# Shell 平台接入规则

开发者可以在没有 Shell 的环境运行自己的产品，独立管理账号、数据和部署。以下规则只约束其作为本平台插件提供的功能。

## 入口与授权

- 申请不等于上架。平台审核具体插件 ID 和版本，管理上线、赋权、升级、暂停和下线。
- 平台用户通过 Shell 入口使用获授权插件。Shell 检查登录、插件状态、用户资格和本机启用状态；插件后台对每次受保护请求再次验证平台插件授权与资源所有者。
- 独立产品的登录、前端角色字段、URL 参数或隐藏菜单不能冒充 Shell 授权。主账号 Cookie、刷新令牌、其他插件数据不得交给第三方。
- 独立产品可按开发者自己的规则运行，但不能借此访问平台授权保护的数据或能力。

## 接口与数据

- Shell 控制外层导航和顶部返回、标题、更多、关闭；插件只绘制业务内容及内部导航。
- manifest 申报唯一 ID、版本、路由、菜单、能力、后端和数据用途。新增能力或变更受审版本须重新提交审核。
- 第三方可有自己的后台和数据库，但不能直连平台数据库或修改平台授权记录。提交时说明数据类别、用途、用户隔离、保留、导出和删除。
- 当前 SDK 是构建时集成接口，插件与 Shell 共享 JavaScript 上下文；它不是恶意代码沙箱。远程隔离和插件专用后台令牌仍待实现。

站外更新不自动改变 Shell 已批准版本。通过本仓库的构建或 manifest 校验不构成安全审核或上线许可。
